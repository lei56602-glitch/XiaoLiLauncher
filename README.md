# 小李桌面（XiaoLi Launcher）

面向 Android TV 的极简、可自由定制桌面启动器，属于「小李全家桶」产品生态。

## 产品定位

默认干净、自由摆放、遥控器优先。让用户回家打开电视后，第一眼看到自己常用的应用，而不是广告、资讯流或复杂推荐。

## 已确认的产品原则

- 无广告、无新闻推荐、无会员订阅、无组件商店。
- 不强制注册或登录账号。
- 默认首页展示用户选择的 5 个常用应用；应用可自由选择、移动、排序。
- 按遥控器上键打开应用抽屉，展示电视已安装应用；返回键回到桌面。
- 时钟、日期、星期、农历、日历、天气可显示、隐藏、移动和调整。
- 桌面组件与应用图标采用直观的编辑模式，支持移动、缩放和布局保存。
- 支持静态图片、动态壁纸和视频壁纸。
- 支持从手机向电视传输图片/视频，并将其选作壁纸；优先研究与「小李全联」互通。
- 设置中心同时提供小李桌面设置，以及真实调用 Android TV / 厂商系统原生设置的入口。
- 电视横屏优先，所有主要交互必须适配方向键、确认键、返回键等遥控器操作。
- 不同电视品牌和 Android 版本的系统入口、权限与后台能力需要逐一兼容验证。

## 已确定的首页视觉基准

- 16:9 电视横屏。
- 蓝色沉浸式全屏壁纸，画面主体保持干净、留白充足。
- 左上角：小李桌面品牌标识。
- 右上角：时钟、日期、农历、天气（默认位置可移动）。
- 下方居中：默认五个常用应用（具体应用由用户选择）。
- 左下角：按上键打开应用抽屉的轻量提示。
- 右下角：网络及设备状态。
- 本轮已确认的首页效果图及其中的品牌图标作为视觉基准，后续不得擅自更换品牌标识或改变整体布局方向。

## 技术路线

- Android 原生 Kotlin。
- 优先适配 Android TV / Google TV 设备。
- 以 HOME Launcher 能力为核心，评估默认桌面设置、开机启动、应用列表、焦点导航和系统设置 Intent 的设备兼容性。
- 壁纸播放需评估视频解码、内存、功耗、生命周期与屏保冲突，避免影响桌面稳定性。

## 开发阶段

1. V0.1：工程骨架、HOME 启动器入口、首页视觉还原。
2. V0.2：应用枚举、五个常用应用、应用抽屉、遥控器焦点导航。
3. V0.3：桌面编辑模式、自由布局、配置持久化。
4. V0.4：静态图片与视频壁纸。
5. V0.5：时间、日期、日历、天气展示与组件移动隐藏。
6. V0.6：桌面设置、系统原生设置入口、手机上传壁纸。
7. V1.0：多设备兼容、性能与稳定性测试、APK 发布。

## 当前开发纪律

先实现可运行、可安装、可操作的基础版本，再逐步增加能力。每个阶段都要构建和测试；不以静态界面冒充已实现功能，不修改已确认的视觉方向，不为了功能数量牺牲简洁体验。

# 小李桌面：电视大屏交互与视觉规范

## 产品原则
- 电视是远距离观看、遥控器操作的设备，不套用手机桌面或普通 PC 窗口布局。
- 首页优先呈现用户常用应用与状态；教学提示、重复说明和装饰性文字不占用主要空间。
- 所有可操作控件必须同时具备清晰焦点态、足够大的命中区域和可预测的方向键路径。
- 视觉统一采用已确认的蓝色沉浸式背景、蓝白科技风、圆角卡片；不加入广告或推广内容。

## 首页
- 保持全屏沉浸式壁纸；品牌标识在左上，时间/日期/农历/天气在右上，常用应用在底部居中，网络与设备状态在右下。
- 常用应用卡片应有完整的外框和明显的焦点反馈，图标按可用卡片宽高自适应，不用固定小图标尺寸。
- 常用应用最多五个，拖动排序与遥控器左右移动保持一致；快传入口是独立功能入口，不挤占应用槽位。

## 应用抽屉
- 使用大面积面板与完整圆角应用卡片；删除“按上键打开抽屉”等不必要教学提示。
- 网格默认偏向大图标：列数 4–6、可见行数 2–4；图标、卡片高度、文字基线、滚动视口与触控命中区域必须由同一套行列参数计算。
- 电视分辨率可提供自动列数默认值，但允许用户手动覆盖；用户设置持久保存。
- 遥控器焦点移动、滚动位置、确认启动和管理常用应用必须保持一致，不允许焦点跑出可视区域。

## 设置中心
- 设置按主题分组，避免把所有选项挤成密集的小按钮；每项修改立即预览并持久保存。
- 至少覆盖壁纸、动态背景、时钟格式、日期/农历/天气显示、组件位置与尺寸、应用抽屉行列、常用应用、系统设置、默认桌面与小李全联入口。
- 系统时间属于 Android 系统设置；桌面只负责显示格式和快捷跳转，不尝试越权修改系统时钟。
- 默认桌面必须经 Android 系统角色/系统选择器确认，不伪造成功状态；厂商系统可能限制第三方桌面。

## 小李全联电视界面
- 使用左侧固定导航栏，右侧宽屏内容区；导航顺序为首页、发送、接收、设备、记录。
- 发送/接收/设备/历史内容使用大卡片与宽行布局，保持触控与遥控器坐标一致。
- 接收请求必须明确显示发送设备、文件数量、总大小，并提供接收/拒绝；传输完成显示结果。
- 不改写已稳定的发现、TLS 身份校验、传输协议与文件完整性校验链路；UI 改造不得侵入传输核心。

## 遥控器与可访问性验收
- 任意页面可通过方向键到达所有主要控件；焦点状态必须明显，确认键执行，返回键回到合理上一级。
- 首次进入页面焦点落在最常用操作；列表滚动时焦点项必须始终可见。
- 不能只改绘制尺寸：点击/触摸命中区域、焦点矩形、滚动计算必须与新布局同步。

## 交付验收
- CI 编译、Lint 与 APK 产物通过只是代码门槛，不等于电视真机验收。
- 必须覆盖不同分辨率与屏幕比例、遥控器方向键/确认/返回、应用启动、设置持久化、默认桌面选择。
- 小李全联必须覆盖手机到电视、电视到手机、手机到手机、平板互传，以及大文件、断线、拒绝、重试和文件完整性。
- 未在真实设备验证的项目明确标记为待实机验收，不得宣称已完成。

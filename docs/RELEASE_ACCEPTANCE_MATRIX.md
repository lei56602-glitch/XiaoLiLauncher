# 小李桌面 / 小李全联交付验收矩阵

本文件区分自动化检查、代码审查与真实设备验收。CI 成功不等于设备互通或发布完成。

## 1. 桌面与大屏视觉
- [ ] 电视 720p、1080p、4K 启动后布局无裁切。
- [ ] 16:9、16:10 与非标准比例下，品牌、时钟、常用应用和状态区不重叠。
- [ ] 首页最多五个常用应用；图标、卡片和焦点框远距离可辨。
- [ ] 快传入口独立，不挤占常用应用槽位。

## 2. 应用抽屉
- [x] 4–6 列、2–4 行设置持久化。
- [x] 图标缩放、绘制单元格、触摸命中与滚动视口使用同一几何参数。
- [x] 新增 DrawerGridMetrics 单元测试：分辨率缩放、行数缩放、滚动命中、间隙拒绝。
- [x] 新增 DPAD 网格焦点边界测试：行首/行尾不跨行跳转，末行缺格时不跳到错误应用。
- [ ] 电视遥控器逐项验证焦点不跑出可视区域，长应用列表滚动无跳项。

## 3. 设置中心与遥控器
- [x] 设置焦点导航抽离为可测试焦点图。
- [x] 新增 SettingsFocusNavigator 单元测试，覆盖控件可达性、水平边界与垂直最近列。
- [x] 设置触摸操作同步焦点状态。
- [ ] 真机验证方向键、确认、返回、设置持久化及恢复默认壁纸二次确认。

## 4. 小李全联界面
- [x] 左侧导航：首页、发送、接收、设备、记录。
- [x] 右侧宽屏区域绘制与触摸坐标统一减去导航栏宽度。
- [x] 接收请求、发送结果和文件完整性提示已有界面逻辑。
- [ ] 电视遥控器逐页验收发送、接收、设备列表和历史记录。
- [ ] 验证触摸、鼠标和遥控器三种输入方式。

## 5. 传输与安全
- [x] 保留现有 TLS 证书指纹固定、首次信任确认、SHA-256 文件校验和续传逻辑。
- [x] 诊断明文模式限制为 debuggable 构建。
- [ ] 手机→电视、电视→手机、手机→手机、平板互传实测。
- [ ] 覆盖大文件、断线、拒绝、取消、重试、断点续传及文件哈希一致性。
- [ ] 记录局域网实测速率和失败日志；不以模拟数据代替。

## 6. 构建与质量
- [x] GitHub Actions 执行 lintDebug、testDebugUnitTest、assembleDebug。
- [x] 自动上传 Debug APK 与 Lint 报告。
- [x] CI 作业设置 30 分钟超时。
- [x] 已对当前交付提交确认 Debug lint、单元测试、Debug APK、临时密钥 Release 构建与签名校验全部通过；最新 Lint 报告共 10 项警告，均已复核。

## 7. 发布与交付
- [x] 已加入 release 签名配置与 tag 发布工作流；等待仓库管理员配置四项受保护 Secrets。

以下任一项未通过，不得标记为正式发布完成：
1. 真实设备双向互传及 SHA-256 校验。
2. 遥控器主流程和设置持久化验收。
3. 正式签名产物验证。
4. 最新提交的 CI 与 Lint 报告检查。

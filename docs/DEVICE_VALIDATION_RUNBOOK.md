# 小李桌面设备实测步骤

此流程用于真实 Android TV、Android 手机和平板验收。CI 只能验证源码、单元测试和构建产物，不能替代以下测试。

## A. 安装与桌面

1. 从最新成功的 Android Actions run 下载 Debug APK。
2. 安装到 Android TV；首次启动后将“小李桌面”设为默认桌面。
3. 分别检查 720p、1080p、4K 分辨率；确认时钟、天气、常用应用、状态信息无裁切或重叠。
4. 打开应用抽屉，分别设置 4、5、6 列及 2、3、4 行；退出再进入，确认设置持久化。
5. 用遥控器逐格移动焦点，特别检查每行首尾、最后一行不满列、滚动边界，不允许跨行误跳。
6. 检查设置中心所有控件、壁纸恢复确认、默认桌面入口和应用管理入口。

## B. 遥控器操作

逐项使用方向键、确认键和返回键：
- 首页五个常用应用；
- 应用抽屉打开、滚动、固定/取消固定；
- 设置中心每个开关、行列设置和壁纸操作；
- 小李全联左侧五个导航目的地；
- 发送文件选择、设备选择、取消；
- 接收开关、来件确认、完成提示；
- 历史记录打开、清空和返回。

记录无法聚焦、焦点丢失、误触或返回层级错误的页面与按键序列。

## C. 文件互传与安全

前提：手机与电视接入同一可信局域网。先在电视打开小李全联接收端，再在手机打开发送端。

1. 手机向电视发送一个小文件，首次连接时核对并确认对端 SHA-256 证书指纹。
2. 发送多个文件，检查文件名、大小、接收目录和完成提示。
3. 发送至少一个 300 MB 以上文件；对比发送前后 SHA-256。
4. 反向执行电视向手机发送，确认双向能力。
5. 测试用户拒绝信任、取消传输、接收端关闭、Wi-Fi 断开、重新连接与续传。
6. 测试手机、电视、平板三种设备组合；记录局域网环境、文件大小、耗时和吞吐量。
7. 确认已信任设备证书发生变化时连接会被拒绝。

不要为了通过测试而关闭证书指纹校验或文件完整性校验。

## D. 记录与故障材料

每次失败至少记录：
- 设备型号、Android 版本、屏幕分辨率；
- 网络类型（Wi-Fi / Ethernet）及是否同一子网；
- 发送方向、文件大小、耗时；
- 失败页面、用户操作顺序和提示文本；
- 对应时间段的 Android logcat。

## E. 发布验收

- 安装最新正式签名 APK，确认签名证书指纹。
- 覆盖升级旧版本，确认应用数据、默认桌面、壁纸和已信任设备状态符合预期。
- 卸载重装后检查首次启动、权限和重新配对。
- 完成所有阻断项后才可标记正式发布。
